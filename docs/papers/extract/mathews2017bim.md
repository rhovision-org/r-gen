# @mathews2017bim — BIM+Blockchain: A Solution to the Trust Problem in Collaboration?

## p.7 — permissioned by qualifications; value proposition

> "A 'Permissioned by Qualifications Blockchain', facilitated by an Oracle…"
>
> "This is in essence 'the new value proposition'."

**Why it matters.** Qualification gates are primary: a validator must hold a credential
that the genesis issuer recognizes. The "value proposition" phrase is the paper-adjacent
anchor for the user-requested ValueProposition primitive; the papers do not define its state
machine.

## p.8 — oracle adjudication

> "An Oracle contract is an adjudicated contract with the added requirement the adjudicator
> … is deemed the most appropriate person to be performing the adjudication."

**Why it matters.** The core Oracle has one adjudicator proved by a credential, not a
weighted voting panel.

## p.9 — reputation and intrinsic value

> "Reputation now is a currency."
>
> "develop a 'new value proposition' to extract reward … also the intrinsic intangible value"

**Why it matters.** Reputation is an extension concern; the core records validation and
approval facts. The value proposition is a separate cell in the user's Pareto core.
