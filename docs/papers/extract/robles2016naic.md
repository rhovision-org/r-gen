# @robles2016naic — Insurance: The Highest and Best Use Case for Blockchain Technology

## p.4 — the three insurability questions

> "1. Can we identify the risk exposure? 2. What is the [mathematical] probability that such
> risk exposure will manifest? 3. If failure occurs, what are the consequences [cost] of that
> failure?"

**Why it matters.** The three questions are the source of the insurability gate. r-gen keeps
risk as an extension so it does not conflate this consequence question with the IMECE
exposure factor.

## p.9 — the oracle as the most appropriate person

> "An Oracle contract is an adjudicated contract with the added requirement the adjudicator
> … is deemed the most appropriate person to be performing the adjudication."

**Why it matters.** The core Oracle names a single adjudicator and checks a credential at
decision time.
